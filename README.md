# terminal-themes

Theme catalog for featherbit terminal. The app downloads `catalog.toml` from this repository
when you open the theme gallery and press Refresh, Install or Update; nothing else is fetched.

## Rules

- One file per theme: `themes/<id>.toml`. The id is a lowercase slug (for example
  `catppuccin-mocha`), equal to the file name, unique and fixed forever once published.
  At most 64 characters, and it must not start with `gallery-` (reserved by the app).
- Permissive licenses only. The theme's `[credit] license` must be one of: `MIT`,
  `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `Unlicense`, `CC0-1.0`, `Zlib`.
- Credits are required. Every `[credit]` field (project, author, url, license, copyright,
  license_file, description) must be present. `url` is `https://` and points to the theme's own
  main project. Copy the upstream license text into `LICENSES/` (plus its NOTICE text for
  Apache-2.0 sources) and point `license_file` at it.
- A theme file is a featherbit terminal color scheme (`name`, optional `font_family` and
  `font_size`, and a `[colors]` table of `#rrggbb` values) plus `id`, `version`, `variant`
  (`dark` or `light`), the `[credit]` table and the `[suggested_font]` table (see below).
- Raise `version` on every change to a theme. Ids never leave the catalog; a withdrawn theme
  is marked `withdrawn = true`, not removed. `ids.txt` is an append-only registry of every id ever
  published (generated by `build`); an id in it never disappears and is never reused.
- Merging to `main` publishes: `catalog.toml` on `main` is what the app downloads.
- Never name or compare to other terminal applications anywhere in this repository (files,
  descriptions, commit messages, pull requests). Credits link to the theme's own main project.

## Suggested font

Every theme suggests a font family that suits it, in a required `[suggested_font]` table:

```toml
[suggested_font]
family = "JetBrains Mono"
url = "https://www.jetbrains.com/lp/mono/"
license = "OFL-1.1"
```

- All three keys are required. `family` is the font's family name as installed, `url` is
  `https://` and points to the font's official page (the foundry's or project's own site, its
  GitHub repository or releases, or its Google Fonts page when its authors publish it there;
  never a mirror), and `license` is the font's SPDX id, one of: `OFL-1.1`, `Apache-2.0`, `MIT`,
  `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `Unlicense`, `CC0-1.0`, `Zlib`.
- Prefer the font the theme's upstream project recommends, when its license is on the list;
  otherwise pick one whose character fits the palette. No family for more than about a third
  of the themes.
- featherbit terminal never ships or downloads fonts. It shows the suggestion with a link that
  opens in your browser when you click it; you install the font yourself and then pick it.
- The suggestion is separate from `font_family`, which applies a font. Changing a theme's
  suggestion raises its `version` like any other change.

## Adding a theme

1. Add `themes/<id>.toml` (with its `[suggested_font]`) and the license text under `LICENSES/`.
2. Run `python3 tools/catalog.py build` to regenerate `catalog.toml`, the table below and
   `previews/derived.svg` (a swatch row for every theme with `derived = true`, where the 16
   colors are this repository's mapping of a palette; `previews` redraws only that file).
3. Run the checks (Python 3.11 or newer, standard library only):

   ```
   python3 -m unittest discover -s tools
   python3 tools/catalog.py check
   python3 tools/catalog.py versions origin/main
   ```

   Low text contrast (foreground on background below 4.5:1) is reported as a warning, not an
   error.
